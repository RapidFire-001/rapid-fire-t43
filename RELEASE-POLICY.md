# Prerelease and update policy

Rapid Fire remains a prerelease while development continues. Each release has its own version, architecture, changes, test coverage, known limits and one versioned app ZIP containing one executable. Application source and private development history are not published.

The README points to the newest recommended prerelease explicitly. Updates are manual downloads. Older releases are retained and marked Superseded; use the recommended version unless instructed otherwise.

If an unsafe release is identified, its page will be marked Withdrawn with the reason and affected version. Its binary download may be removed while explanatory history remains. Do not use a withdrawn version, and do not retry a stopped vehicle operation merely by switching versions.

Reported issues should identify app version, Windows version, GT driver version, installed controller OS and operation stage. Do not post VINs, raw BINs, enrollment files or unredacted vehicle logs publicly. Preserve evidence locally and wait for guidance on a private support route when needed.

Passing software models or one vehicle trial does not establish universal controller compatibility. Release notes distinguish recorded hardware results, software checks and remaining validation.
